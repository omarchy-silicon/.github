# Support

Omarchy Silicon is in active development. The current repositories contain foundation and in-progress work. No Apple Silicon board is currently supported or qualified, and there is no supported Omarchy Silicon installer, release image, or recovery release.

M1 and M2 are first staging targets only. A build, green CI result, successful boot, chip-name match, or source-code match does not establish support. Support is granted only for an exact board/profile after the project records kernel, device-tree, firmware, boot, graphics, installer, recovery, release, and physical qualification evidence.

There are no installation instructions or supported recovery steps to provide from this organization yet. Do not treat artifacts from branches, forks, upstream projects, or CI as supported releases.

For an engineering report, use the central platform repository's issue workflow and include the exact machine, Apple chip variant, board/profile, firmware and boot artifacts, software revisions, reproduction steps, and logs with sensitive information removed: https://github.com/omarchy-silicon/omarchy-apple-platform/issues

For project coordination and design questions, use the central engineering discussions: https://github.com/omarchy-silicon/omarchy-apple-platform/discussions

For security vulnerabilities, follow SECURITY.md and use the private advisory interface instead of a public issue.
